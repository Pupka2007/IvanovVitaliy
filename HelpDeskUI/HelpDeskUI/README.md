# HelpDesk - Система учета обращений в техподдержку

**Автор:** Ivanov Vitaliy

## Описание проекта

Система учета обращений в техподдержку (HelpDesk) — это приложение для автоматизации обработки заявок пользователей. Проект состоит из двух частей:
- **REST API** — серверная часть для управления заявками
- **Windows Forms UI** — клиентский интерфейс для работы с заявками

## Возможности

- ✅ Создание новых обращений
- ✅ Просмотр списка всех заявок
- ✅ Изменение статуса заявки (New, InProgress, Resolved, Cancelled)
- ✅ Удаление заявок
- ✅ Хранение данных в JSON-файле
- ✅ Взаимодействие через REST API

## Технологии

| Компонент | Технология |
|-----------|------------|
| Язык | C# |
| Платформа | .NET 8.0 |
| API | ASP.NET Core Web API |
| Интерфейс | Windows Forms |
| Хранение данных | JSON файл |
| HTTP клиент | HttpClient + System.Net.Http.Json |
